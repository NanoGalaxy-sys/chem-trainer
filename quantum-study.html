Postulates and operators

  • The state is a wavefunction ψ. |ψ|² is probability density. ψ must be normalizable, single-valued, continuous and finite.
  • Every observable is a Hermitian operator: real eigenvalues, orthogonal eigenfunctions for different eigenvalues.
  • A measurement returns only an eigenvalue. Expectation value: ⟨A⟩ = ∫ψ*Âψ dτ.
  • Stationary states obey ĤΨ = EΨ.

Commutators (often tested)

[x, p] = iħ    [Lx, Ly] = iħLz    [L², Lz] = 0

If [A, B] = 0, both can be known simultaneously. Otherwise ΔA·ΔB ≥ ½|⟨[A,B]⟩|, so Δx·Δp ≥ ħ/2.

Particle in a 1D box (length L)

ψn = √(2/L) sin(nπx/L)    En = n²h²/(8mL²)
  • n = 0 is not allowed, so there is a zero-point energy. State n has n−1 nodes.
  • ⟨x⟩ = L/2 and ⟨p⟩ = 0 for every state. ⟨p²⟩ = n²h²/4L².
  • Spacing En+1 − En = (2n+1)h²/8mL² grows with n and shrinks with larger L or m.
  • 3D box: E = (h²/8m)(nx²/Lx² + ny²/Ly² + nz²/Lz²). A cube gives degeneracy.
  • Free-electron model: butadiene (4 π electrons) HOMO n=2, LUMO n=3, ΔE = 5h²/8mL². Longer conjugation means longer absorption wavelength.

Harmonic oscillator

Ev = (v + ½)ħω    ω = √(k/μ)
  • Zero-point energy ½ħω. Levels are equally spaced. Selection rule Δv = ±1.
  • ψv = NvHv(ξ)e−ξ²/2. H₀ = 1, H₁ = 2ξ, H₂ = 4ξ² − 2. Parity is (−1)v.
  • Virial theorem: ⟨T⟩ = ⟨V⟩ = E/2.
  • Anharmonic: Ev = (v+½)ħω − (v+½)²ħωxe. Levels converge, overtones become weakly allowed.
  • ZPE ∝ 1/√μ. Heavier isotopologues have lower ZPE, which underlies the kinetic isotope effect.

Hydrogen atom

En = −13.6 Z²/n² eV
  • l = 0 to n−1, m = −l to +l. Energy depends on n only, so each level is n²-fold degenerate (ignoring spin).
  • Radial nodes = n − l − 1. Angular nodes = l. Total = n − 1.
  • |L| = √(l(l+1)) ħ, Lz = mħ. Spin s = ½, |S| = (√3/2)ħ.
  • For 1s, the most probable r is a₀ but ⟨r⟩ = 1.5 a₀.
  • Only s orbitals have nonzero density at the nucleus.

Tunneling

T ∝ e−2κL    κ = √(2m(V−E))/ħ
  • Transmission falls exponentially with barrier width and particle mass.
  • H tunnels far more readily than D, which is why tunneling shows up in isotope effects.
  • Applications: scanning tunneling microscopy, proton transfer, α decay.
